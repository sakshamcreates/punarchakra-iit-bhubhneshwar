# ReValue Frontend Starter

## Run

```bash
npm install
npm run dev
```

## Recommended workflow

Use Codex one prompt at a time from `CODEX_PROMPTS.md`.

Do not ask Codex to generate the entire frontend at once. Build the demo path first:

1. Foundation
2. Home
3. Sell wizard
4. AI analysis
5. Recommendation results
6. Dashboard
7. Scrap locker
8. Auctions
9. Marketplace
10. Final polish

## Current routes

- `/`
- `/sell`
- `/sell/results`
- `/dashboard`
- `/auctions`
- `/scrap`
- `/marketplace`

The starter is intentionally simple and uses only mock data.
